# Michael J. Natan

- 类型：师承扩展人物
- Penn State 化学研究组负责人，研究胶体金属纳米粒子、表面增强拉曼及光谱。 [ACS Pittsburgh 讲座档](https://www.pittsburghacs.org/wp-content/uploads/2011/10/cruc_sep02.pdf) · [Penn State 原论文书目](https://pure.psu.edu/en/publications/protein-colloid-conjugates-for-surface-enhanced-raman-scattering-/)

## 师承

- 博士后课题组成员：[[人员 - Penn State - Christine Keating - 481ac589|Christine Keating]]。ACS Pittsburgh 2002 年讲座原册具名 Keating 获博士后在 Paul Weiss 与 Michael Natan 两个实验室任 postdoctoral associate。Penn State 原档列任期 1997–1999，1999–2001 Research Assistant Professor 另列。UCLA 履历核 Paul S. Weiss 当时在 Penn State。博士后组属可信度高，个人正式指导待任用档。 [ACS Pittsburgh 同期讲座原档](https://www.pittsburghacs.org/wp-content/uploads/2011/10/cruc_sep02.pdf) · [Penn State 官方任用史](https://www.psu.edu/news/eberly-college-science/story/christine-keating-named-shapiro-professor-chemistry) · [Penn State 作者档](https://pure.psu.edu/en/publications/protein-colloid-conjugates-for-surface-enhanced-raman-scattering-/) · [UCLA Weiss 履历](https://www.chemistry.ucla.edu/directory/weiss-paul-s/)

- 博士阶段课题组成员：[[人员 - Penn State - Christine Keating - 481ac589|Christine Keating]]。2002 年 ACS Pittsburgh 讲座原册将 Keating 的 Penn State 研究生工作明确置于 Michael Natan 的实验室，博士前方向为金属纳米粒子与表面增强拉曼。该册研究生段拼作 Nathan、博后段作 Natan，Penn State 论文档核同人拼写 Michael J. Natan。博士论文正式导师字段待学位原卷，记博士课题组负责人。 [ACS Pittsburgh 同期讲座原档](https://www.pittsburghacs.org/wp-content/uploads/2011/10/cruc_sep02.pdf) · [Penn State 官方任用史](https://www.psu.edu/news/eberly-college-science/story/christine-keating-named-shapiro-professor-chemistry) · [Penn State 作者档](https://pure.psu.edu/en/publications/protein-colloid-conjugates-for-surface-enhanced-raman-scattering-/) · [UCLA Weiss 履历](https://www.chemistry.ucla.edu/directory/weiss-paul-s/)
