# Daniel López

- 类型：师承扩展人物
- Penn State 电气工程与计算机科学教授，曾领导 Argonne CNM 纳米加工与器件组。研究包括微纳机电系统、光学微系统及纳米制造。 [Penn State 任用档](https://news.engr.psu.edu/2020/eecs-faculty-appointments.aspx)
