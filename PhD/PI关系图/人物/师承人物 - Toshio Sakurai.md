# Toshio Sakurai

> [!info] 师承扩展人物
> 东北大学原始履历记载其 1974 年获 Penn State 物理博士，1977–1981 年在 Penn State 物理系任助理教授及副教授，后任东北大学材料研究所教授。研究原子尺度表界面。 [东北大学本人履历](https://www.wpi-aimr.tohoku.ac.jp/en/topics/pdf/AIMR_News_vol1.pdf)

## 师承

- 博士阶段候选关系：[[人员 - Arizona State - Robert Culbertson - e264961e|Robert Culbertson]]。ASU 教师档列全名 Robert John Culbertson、Pennsylvania State University 1979 博士。ORNL 当年研究书目列 Applications of magnetic-sector atom-probe field-ion microscopy、Culbertson, R. J., Jr.、1979、UMI 8010043，为待核学位原文的题名和索书线索。东北大学托管 Sakurai CV 显示其 1977–1981 任 Penn State 物理教师，同期原文列两人原子探针场离子显微合著。Toshio Sakurai 仅为低可信博士导师候选，正式导师待论文签署页。 [ASU 教师原档](https://catalog.asu.edu/files/shared/archives/Faculty_List_2008_2009_Final.pdf) · [ORNL 论文书目](https://www.osti.gov/servlets/purl/6047469) · [东北大学本人履历](https://www.wpi-aimr.tohoku.ac.jp/en/topics/pdf/AIMR_News_vol1.pdf) · [同期原论文](https://panitz.unm.edu/home/Publications_files/Ultramicroscopy%204%2C%20367%20%281979%29.pdf)
